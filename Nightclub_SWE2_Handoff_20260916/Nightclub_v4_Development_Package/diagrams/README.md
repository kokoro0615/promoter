# Mermaid図面 v4

`index.html`をローカルのブラウザで開くと、外部CDNなしで生成済みSVGを閲覧できる。原本は16件の`.mmd`。ERは概要1・全体1・領域別7、その他は業務フロー1・シーケンス4・状態遷移2。

ER全体はR1参照モデル67テーブル。PK/FKと主要カラムを表示し、全817列の詳細はデータ辞書を参照。全体ERには複合FKの追加関係も描くため線が多い。日常のレビューは領域別を使用する。R2〜R4の全物理モデル完成を意味しない。

各図はMermaidエンジンで構文解析・SVG生成を実施した。結果はvalidation/mermaid_results.json。図面と参照SQLの適用・DB並列試験は別工程。SVGにフォントファイルや描画エンジンは同梱しない。
