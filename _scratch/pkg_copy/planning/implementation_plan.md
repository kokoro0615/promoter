# 実装計画・見積の入口

要件方針は採用済み。期間・金額は未見積であり、ファイル数や参照テーブル数から納期を約束しない。

|順序|担当|期限／ゲート|完了条件|
|---|---|---|---|
|1 ベースラインと台帳レビュー|PM・店舗責任者・Tech Lead|実装契約前|v4変更、143機能のRelease、設計提案、未決定の所有者を合意|
|2 主要画面と取引の試作|UX・Backend・入口担当|最初の実装スプリント前|名前検索・常連本人・入口通常承認・担当者切替・部分入場を実演|
|3 縦の受付機能|開発・QA|EP02〜12の終了判定|個人/端末認証から実入場まで連続し、並列・権限・通信断試験合格|
|4 VIP・金銭|開発・経理|R1実決済前|PSP/在庫/取消/返金/支払充当/報酬を手計算と照合|
|5 運用受入|店舗責任者・SRE・QA|R1本番判定前|当日設定・端末・復元・連絡体制・受入試験を承認|
|6 限定営業|店舗責任者・開発|対象4営業終了時|登録率・再確認件数・精算差額・障害を記録し拡大判定|

管理画面に入力する実料金・人数は、機能設計のハードコードではない。未入力の営業は公開できない。PSP・本人認証の接続方式・RLS実装・補助CRUDは該当epicのDefinition of Readyを満たしてから着手する。R2〜4は削除ではなく後続Must。
