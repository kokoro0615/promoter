# v3 → v4 変更一覧

|対象|v3|v4|関連|
|---|---|---|---|
|常連の意味|客／紹介者の初回対象は未定|常連のお客様と確定。紹介者権限は別|V4-CUS-01、D-01|
|料金・人数・期間|設定の具体値は台帳で未定|管理画面で決められる仕様を確定。実運用値は公開前設定|V4-CFG-01〜10、D-02|
|主受付|名前／QRの併用|名前検索中心。QRは代替として維持|V4-CUS-02〜04|
|入口承認|一般入口ロールは不可、例外責任者対応|通常から入口も指定者と同じ申請を判断|V4-APR-01〜07|
|入口の待機|通知再送・代行責任者の検討|不在・到着・時間を承認権限の条件にしない|V3-APR-06改訂|
|入口端末|個人中心、共用は追加|店舗共用tablet/phoneを標準。個人主体は分離|V4-KSK-01〜08|
|成果物|文書・論理モデルの表|67表参照モデル、Mermaid、API、設定Schema、試験、追跡表等|V4-DEV-01〜07|

指定承認者の既存3名枠は残し、入口担当の人数をその枠に含めない。入口の通常承認をOVERRIDEと記録しない。v2/v3の143機能とR1〜R4を削らない。新しい競合の機能追加は自動的に開発契約へ加えない。

設計の追加：端末の個人PIN、idle値、ロック方式、モデル・APIは設計案。料金・人数の具体例はテスト用。SQLは本番ポリシー実装ではない。未確定事項はplanning/decision_register.csvへ。
